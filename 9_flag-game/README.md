# [실습-9] 청기 올려?! 백기 올려?!

> 노션 [4] 다양한 이벤트 알아보기 › 2번 · 권장 시간 18분

## 목표

mousedown·mouseup과 event.button으로 왼쪽/오른쪽 버튼을 구분하고 contextmenu 기본 동작을 막아 봅니다.

## 진행 방법

1. `starter/index.html`을 브라우저로 엽니다. (VS Code Live Server 권장)
2. 개발자 도구(F12)의 Console 탭을 열어 둡니다.
3. `starter/script.js`의 `// TODO:` 주석을 위에서부터 하나씩 채웁니다.
4. 다 채웠으면 아래 **예상 결과**와 화면 · 콘솔 출력을 비교해 보세요. 풀이는 수업 시간에 함께 봅니다.

## 요구사항

1. mousedown: event.button이 0이면 청기, 2면 백기를 올리고 judge() 호출하기
2. mouseup: 같은 방법으로 해당 깃발 내리기
3. contextmenu: preventDefault로 오른쪽 클릭 메뉴 막기

## 예상 결과

**화면** — 시작을 누르면 지시가 나옵니다. 영역 안에서 왼쪽 버튼을 누르고 있으면 청기, 오른쪽 버튼을 누르고 있으면 백기가 올라가고, 10문제가 끝나면 점수가 표시됩니다.

**Console**

```
지시: 청기 올려! / 올린 깃발: 청기 → 성공
지시: 백기 올려! / 올린 깃발: 청기 → 실패
...
```

> 지시는 무작위라서 출력은 매번 달라요. 오른쪽 클릭을 해도 브라우저 메뉴가 뜨지 않으면 성공입니다.
