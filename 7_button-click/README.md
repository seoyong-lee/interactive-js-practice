# [실습-7] 버튼 클릭 이벤트

> 노션 [3] 이벤트 살펴보기 › 2번 · 권장 시간 10분

## 목표

addEventListener로 핸들러를 등록하고 같은 버튼에 여러 핸들러를 달거나 removeEventListener로 지워 봅니다.

## 진행 방법

1. `starter/index.html`을 브라우저로 엽니다. (VS Code Live Server 권장)
2. 개발자 도구(F12)의 Console 탭을 열어 둡니다.
3. `starter/script.js`의 `// TODO:` 주석을 위에서부터 하나씩 채웁니다.
4. 다 채웠으면 아래 **예상 결과**와 화면 · 콘솔 출력을 비교해 보세요. 풀이는 수업 시간에 함께 봅니다.

## 요구사항

1. +1, -1, 초기화 버튼에 click 핸들러 등록하기
2. +1 버튼에 핸들러를 하나 더 등록해 클릭 횟수 세기
3. 쿠폰 핸들러 안에서 removeEventListener로 자기 자신을 제거하기
4. handleCoupon을 소괄호 없이 핸들러로 등록하기

## 예상 결과

**화면** — +1을 세 번, -1을 한 번 누르면 카운트는 2, "+1 버튼 클릭 기록: 3번"이 표시됩니다. 쿠폰 받기는 두 번 눌러도 한 번만 발급됩니다.

**Console**

```
카운트: 1
카운트: 2
카운트: 3
카운트: 2
쿠폰 발급!
```

> 쿠폰 버튼을 두 번 눌러도 "쿠폰 발급!"은 한 번만 찍힙니다.
