# [실습-4] 동적 리스트 만들기

> 노션 [2] 브라우저와 자바스크립트 › 10번 · 권장 시간 14분

## 목표

createElement, append, prepend, remove로 할 일 목록을 만들고 지우고 옮겨 봅니다.

## 진행 방법

1. `starter/index.html`을 브라우저로 엽니다. (VS Code Live Server 권장)
2. 개발자 도구(F12)의 Console 탭을 열어 둡니다.
3. `starter/script.js`의 `// TODO:` 주석을 위에서부터 하나씩 채웁니다.
4. 다 채웠으면 아래 **예상 결과**와 화면 · 콘솔 출력을 비교해 보세요. 풀이는 수업 시간에 함께 봅니다.

## 요구사항

1. span을 만들어 할 일 글자를 넣고 li 안에 넣기
2. "맨 위로" 버튼을 만들고 누르면 prepend로 li를 맨 앞으로 옮기기
3. "삭제" 버튼을 만들고 누르면 remove로 li를 지운 뒤 개수 갱신하기
4. 추가 버튼을 누르면 새 li를 append로 맨 끝에 붙이고 개수 갱신하기

## 예상 결과

**화면** — "장보기"를 추가 → 2번째 항목 삭제 → 3번째 항목을 맨 위로 옮기면 목록이 장보기, 코드잇 강의 듣기, 운동하기 순서가 되고 "총 3개"가 표시됩니다.

**Console**

```
추가: 장보기 (총 4개)
삭제: 실습 코드 정리하기 (총 3개)
이동: 장보기 → 맨 위
```

> 이미 화면에 있는 요소를 prepend/append하면 복사되지 않고 그 자리로 이동합니다.
