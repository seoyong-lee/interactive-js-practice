# [실습-2] DOM 트리 탐색하기

> 노션 [2] 브라우저와 자바스크립트 › 5번 · 권장 시간 10분

## 목표

item3(메뉴 3)을 기준으로 부모·자식·형제 요소를 찾아 봅니다.

## 진행 방법

1. `starter/index.html`을 브라우저로 엽니다. (VS Code Live Server 권장)
2. 개발자 도구(F12)의 Console 탭을 열어 둡니다.
3. `starter/script.js`의 `// TODO:` 주석을 위에서부터 하나씩 채웁니다.
4. 다 채웠으면 아래 **예상 결과**와 화면 · 콘솔 출력을 비교해 보세요. 풀이는 수업 시간에 함께 봅니다.

## 요구사항

1. children, querySelector(".active")로 메뉴 자식 수와 활성 메뉴 출력하기
2. parentElement로 부모를 찾아 id 출력하고 mark(부모, "parent")로 표시하기
3. children, firstElementChild, lastElementChild로 자식 요소 출력하기
4. previousElementSibling, nextElementSibling으로 형제 요소 출력하고 mark()로 표시하기

## 예상 결과

**화면** — 부모 ul은 주황 점선, 메뉴 2는 초록 테두리, 메뉴 4는 파란 테두리로 표시됩니다.
