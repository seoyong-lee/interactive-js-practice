# interactive-js-practice

**인터랙티브 자바스크립트** 실습 코드입니다.
DOM 선택부터 다양한 이벤트까지, 노션 강의 자료의 실습 12개를 순서대로 담았습니다.

## 시작하기

```bash
git clone https://github.com/seoyong-lee/interactive-js-practice.git
cd interactive-js-practice
```

각 실습 폴더의 `starter/index.html`을 브라우저로 열고 개발자 도구(F12) Console 탭을 함께 띄워 두세요.
VS Code의 **Live Server** 확장으로 열면 저장할 때마다 화면이 새로고침됩니다.

## 실습 규칙

- HTML과 CSS는 이미 완성되어 있어요. `script.js`만 수정합니다.
- `// TODO:` 주석 아래에 코드를 작성하세요. 주석에 적힌 메서드나 프로퍼티를 쓰면 됩니다.
- "수정하지 않아도 돼요"라고 적힌 도우미 함수는 그대로 사용하세요.
- 1~6번은 아직 `addEventListener`를 배우기 전이라 `onclick` 프로퍼티로 이벤트를 연결합니다.
- 완성 코드는 사용법 예시로 실습-1에만 넣었어요. 나머지 실습은 각 폴더 README의 **예상 결과**와 비교해 스스로 확인하고, 풀이는 수업 시간에 함께 봅니다.
