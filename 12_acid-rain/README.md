# [실습-12] 코드잇 산성비

> 노션 [4] 다양한 이벤트 알아보기 › 10번 · 권장 시간 22분

## 목표

input, change, focus, blur 이벤트로 타자 게임을 완성합니다.

## 진행 방법

1. `starter/index.html`을 브라우저로 엽니다. (VS Code Live Server 권장)
2. 개발자 도구(F12)의 Console 탭을 열어 둡니다.
3. `starter/script.js`의 `// TODO:` 주석을 위에서부터 하나씩 채웁니다.
4. 다 채웠으면 아래 **예상 결과**와 화면 · 콘솔 출력을 비교해 보세요. 풀이는 수업 시간에 함께 봅니다.

## 요구사항

1. input: 입력할 때마다 입력값으로 시작하는 단어에 match 클래스 붙이기
2. change(Enter): 같은 단어가 있으면 지우고 점수 올린 뒤 입력창 비우고 clearMatch() 부르기
3. blur: 진행 중이면 멈추고 일시정지 안내 + paused = true / focus: paused일 때만 이어서 진행

## 예상 결과

**화면** — 시작을 누르면 위에서 단어가 떨어집니다. 글자를 칠 때마다 맞는 단어가 노랗게 표시되고 Enter로 맞히면 단어가 사라지며 점수가 오릅니다. 단어가 땅에 닿으면 목숨이 줄고 입력창 밖을 클릭하면 일시정지됩니다.

**Console**

```
맞힌 단어: const
맞힌 단어: dataset
놓친 단어: querySelector
...
```

> 단어는 무작위로 나와서 출력은 매번 달라요.
