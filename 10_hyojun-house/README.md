> 노션 [4] 다양한 이벤트 알아보기 › 6번 · 권장 시간 18분

## 목표

mouseover와 relatedTarget으로 방 사이 이동을 기록하고 mouseenter/mouseleave와 차이를 비교합니다.

## 진행 방법

1. `starter/index.html`을 브라우저로 엽니다. (VS Code Live Server 권장)
2. 개발자 도구(F12)의 Console 탭을 열어 둡니다.
3. `starter/script.js`의 `// TODO:` 주석을 위에서부터 하나씩 채웁니다.
4. 다 채웠으면 아래 **예상 결과**와 화면 · 콘솔 출력을 비교해 보세요. 풀이는 수업 시간에 함께 봅니다.

## 요구사항

1. 집(#house)에 mouseenter / mouseleave를 등록해 상태 문구 바꾸기
2. mouseover에서 target과 relatedTarget의 방 이름 구하기
3. 같은 방 안에서 가구와 방 사이를 오간 경우는 무시하고 방이 바뀔 때만 기록하기
4. 지금 들어온 방에만 here 클래스 붙이기

## 예상 결과

**화면** — 마우스를 집 안으로 옮기면 "효준이가 집에 들어왔어요!"가 표시되고 방을 옮길 때마다 오른쪽에 "거실 → 주방" 같은 이동 기록이 쌓입니다.

**Console**

```
밖 → 현관
현관 → 거실
거실 → 주방
...
```

> 마우스를 움직인 경로에 따라 출력이 달라요. 가구(이모지) 위로 움직여도 기록이 늘지 않으면 성공입니다.
